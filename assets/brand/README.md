`tangerine.png` and the macOS icon variants are generated with AppKit by
`scripts/generate-tangerine-icon.swift`: a charcoal tile, orange fruit, green
leaf and cream play mark. Regenerate by passing the repository root to the script.
The original `myvlc.png` is retained as a historical source asset.

`tmdb.svg` is TMDB's approved alternate short blue logo, downloaded
from https://www.themoviedb.org/about/logos-attribution. It appears alongside
the required notice in Settings → Metadata providers & credits. It is provider
attribution, not Tangerine branding or an endorsement.

The SVG CSS class fill is expressed as an equivalent gradient presentation
attribute for flutter_svg compatibility; geometry, proportions and colors are unchanged.
